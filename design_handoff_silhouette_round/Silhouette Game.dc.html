Layout → spec bindings

Adapting to iPadLayout

Masks are square (256×256), so the stage is locked to aspect-ratio: 1 and centered. One column at both sizes: timer → stage → stats → feedback → answers. The control group is content-height and the stage absorbs whatever height is left, capped by the column width — so the iPad's extra 240pt goes into the mask (≈366 → 476pt square) rather than into filler or taller buttons. Type, rules and touch targets step up with the breakpoint (56 → 74pt rows, 17 → 22pt labels).

Timer bar§13.3

Drains against an absolute deadline, not a counter. Ticks ~4×/s for smooth motion but reads from wall clock, so re-renders can't extend it. Turns accent red under 10s. Correct answers never reset it. Full width at both sizes.

Score · Named · Streak§14

score, correct_count, and a streak counter that is new product scope — derived client-side from consecutive first-try correct answers, never affecting points.

Silhouette stage§5.2 · §16

Serves the cached mask at data/silhouettes/{id:03d}.png, letterboxed inside a fixed cell so shapes don't jump between questions. On a correct guess the mask cross-fades to grayscale artwork with a sweep, then advances after ~700ms.

Answer list§10 · §11

Four stacked rows, labels flush left — one target plus three get_distractor_ids(difficulty) picks, shuffled with the persisted question seed so order survives a re-render. The trailing cell shows the points this guess is still worth.

Wrong guess§12.1

Shakes 380ms in accent red, then collapses out of the stack — the row is in removed_ids and cannot be submitted again. Remaining rows reflow up inside a reserved four-row cell, so the stage never moves.

Correct guess§12.2 · §12.3

3/2/1/0 by attempt via points_for_attempt(). The row fills solid ink; awards, reveals, increments the count, then pulls the next target from the shuffled pool on the same deadline.

Expiry & result§13.4

Guesses stop being accepted the moment the deadline passes — including one in flight. Reveals the final identity and artwork, reports score, count and session best, and offers a fresh round. Missing artwork must still show the summary.

Setup error§15

Every SetupError renders as one screen: what's missing, the exact expected path, and the command that fixes it. Never an unhandled exception, never a blank round.

Not built hereOpen

No give-up action (§13.4 notes it as optional scope), no difficulty picker in the round — difficulty is a build-time prop. Landscape iPad and split-view widths reuse the iPad rule; below 380px the answer rows drop the points cell rather than shrink the label. Sound and haptics are one toggle; wire it to the Web Vibration API and short sample playback.
